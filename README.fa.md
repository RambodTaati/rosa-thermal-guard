# محافظ دمای رزا (Rosa Thermal Guard)

[English](README.md) · **فارسی** · [العربية](README.ar.md) · [简体中文](README.zh-CN.md)

برنامه‌ای کوچک برای System Tray ویندوز که نمی‌گذارد **دمای پردازنده و کارت گرافیک به ۱۰۰ درجه برسد**.
وقتی دما بالا می‌رود، کارها را قدم‌به‌قدم کند می‌کند و وقتی خنک شد، سرعت کامل را برمی‌گرداند.

![Rosa Thermal Guard](../../releases/download/v1.1.0/screenshot-fa.png)

## امکانات
- نمایش زندهٔ دمای پردازنده و کارت گرافیک با عقربه‌های دایره‌ای و نمودار ۵ دقیقهٔ اخیر
- آیکون رنگی در System Tray: سبز = عادی، نارنجی = در حال خنک‌سازی، قرمز = داغ، خاکستری = متوقف
- کند کردن پردازنده از راه Power Plan ویندوز («حداکثر توان پردازنده» برای همهٔ هسته‌ها، با برق و با باتری)
- کنترل کارت انویدیا: محدود کردن توان (`nvidia-smi -pl`)، و اگر درایور اجازه نداد، محدود کردن فرکانس (`nvidia-smi -lgc`)، و در غیر این صورت پایین آوردن اولویت برنامه‌ها
- لپ‌تاپ‌های GIGABYTE: پیش از هر کاهش سرعت، فن‌ها را از طریق رابط ACPI-WMI خود GIGABYTE روی حداکثر می‌گذارد (CPU ۸۵ / GPU ۸۳ درجه) و پس از خنک شدن (۲۰ ثانیه زیر ۷۵ / ۷۳ درجه)، هنگام خروج و هنگام حذف برنامه، حالت قبلی فن را برمی‌گرداند
- در دمای بحرانی، اولویت سنگین‌ترین برنامه‌ها را پایین می‌آورد و به برنامه‌های سیستمی دست نمی‌زند
- هنگام خروج، حذف برنامه یا بعد از خطا، همهٔ تنظیمات اصلی را برمی‌گرداند
- توقف ۱۵ دقیقه‌ای از منوی Tray (اگر دمای پردازنده به ۹۷ درجه برسد، خودکار لغو می‌شود)
- چهار زبان: فارسی، English، العربية، 简体中文 (تشخیص خودکار و قابل تغییر در پنجره)
- اجرای خودکار همراه ویندوز با دسترسی مدیر، بدون پیام UAC در هر بار ورود

## پیش‌نیازها
- ویندوز ۱۰ یا ۱۱، ۶۴ بیتی
- حساب کاربری مدیر (Administrator)
- درایور **PawnIO** برای خواندن دمای پردازنده (https://pawnio.eu)؛ اگر نصب نباشد، نصب‌کننده خبر می‌دهد
- برای کنترل کارت گرافیک: درایور انویدیا با `nvidia-smi` (اختیاری)

## نصب
فایل `RosaThermalGuard-Setup-1.1.0.exe` را از بخش Releases بگیرید، با `SHA256SUMS.txt` مقایسه کنید و اجرا کنید.

> نصب‌کننده **امضای دیجیتال ندارد**، پس ممکن است SmartScreen ویندوز هشدار بدهد.
> اگر به این نسخه اطمینان دارید (اول SHA-256 را چک کنید)، روی **More info ← Run anyway** بزنید.

## چطور کار می‌کند
هر ۲ ثانیه سنسورها خوانده می‌شوند.

| | شروع خنک‌سازی | حالت بحرانی | برگشت |
|---|---|---|---|
| پردازنده | از ۹۰ درجه: ۱۰۰ ← ۹۹ (بدون توربو) ← ۸۵ ← ۷۰ ← ۵۵ درصد | از ۹۵ درجه: کم کردن اولویت ۳ برنامهٔ سنگین | زیر ۸۰ درجه به مدت ۲۰ ثانیه، قدم‌به‌قدم |
| کارت انویدیا | از ۸۸ درجه: کم کردن توان یا سقف فرکانس ۷۵ ← ۵۵ ← ۴۰ درصد | | زیر ۷۸ درجه به مدت ۲۰ ثانیه |

همهٔ عددها در فایل `config.json` پوشهٔ نصب قابل تغییرند. گزارش‌ها در `%ProgramData%\RosaThermalGuard\guard.log` هستند.

## محدودیت‌ها
- واکنش برنامه از فاصلهٔ خواندن سنسور سریع‌تر نیست؛ ممکن است توربو برای ۲ تا ۴ ثانیه دما را به حد بالا برساند.
- درایور بسیاری از لپ‌تاپ‌ها محدودیت توان کارت گرافیک را قفل می‌کند؛ در این حالت از سقف فرکانس یا اولویت استفاده می‌شود.
- کارت‌های AMD و Intel فقط با اولویت برنامه‌ها کنترل می‌شوند.
- نرم‌افزار سازندهٔ لپ‌تاپ ممکن است Power Plan را تغییر دهد.

## حذف برنامه
Settings ← Apps ← Rosa Thermal Guard ← Uninstall. برنامه متوقف می‌شود، تنظیمات اصلی برمی‌گردد و Task و فایل‌ها پاک می‌شوند.
